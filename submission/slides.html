An agentic AI system for evidence-backed analysis of evolving 5G incidents — every statement a quotation with a checkable source.

Evaluation environment: ITU AI for Good Sandbox

The problem

One incident, many laws, all at once

A 5G incident rarely arrives complete. A latency complaint becomes a security event, then a hospital service carrying patient data, then a question of who must be told — and within how many hours.

  • Each step pulls in different Indian law, institutions and standards.
  • Duties interact — one instrument is made under another — and point to the same incident with different deadlines and recipients.
  • A single answer at the start cannot follow that; keyword search finds provisions but does not connect or check them.
The solution

Follow the incident, chunk by chunk

  • For each chunk, a swarm orchestrator activates only the specialists the new facts justify — seven agents.
  • Each agent searches only its own knowledge base and quotes the law with source, section and page — never from memory.
  • A Verifier checks every claim against a separate Canonical KB.
  • A Coordinator sorts verified findings into five categories and writes a hash-chained audit trail.
What makes it defensible

Evidence-first, not generated

Remove the language model from the adviser and the evidence, the citations and the verdicts still stand.

  • No generative model in the path — agents quote; the Coordinator organises what the Verifier checked.
  • Support decided by text, never by similarity, confidence or a disclaimer label.
  • Two authorities never conflated: Indian law vs international standards (reference only).

Verification

Checked, categorised, nothing overclaimed

Four Verifier outcomes

VERIFIED INCOMPLETE UNSUPPORTED CONFLICT

On the live corpus nothing is VERIFIED — amendment histories not yet confirmed — so supported claims are INCOMPLETE, stated plainly.

Five assessment categories

Confirmed facts · Evidence-backed · Uncertain · Conflicts (both sides kept) · Potential gaps (for a human).

Cross-domain links are drawn only from evidence: shared provision, instrument basis (one instrument's text names the Act the other cites), or parallel reporting — never because two agents are active.

The contained attack sandbox

Induce an attack, see law + fix

  • A simulated 5G core (gNB, AMF, SMF, UPF, UDM, AUSF, NEF, NRF, OAM) — Python state, no real network, no exploit code.
  • Two panels: Policy (Indian obligations, file + page) and Technical (NF health + playbook).
  • Agent runs safe fixes automatically; before escalating it stops: [1] Agent runs · [2] I'll run · [3] Stop.
  • "Resolved" is decided by the lab's own checks — never by the agent's claim.

13 attacks in the catalog · 276 PDFs indexed once across 9 categories (bge-small, CPU, FAISS) · deterministic offline fallback if no API key.
